## 태그

글의 front matter에 `tags`를 쓰면 글 위의 메타 정보에 태그 링크가 생기고, 링크를 누르면 태그 페이지로 이동합니다.

```yaml
---
title: 글 제목
tags: [접근성, 가이드]
---
```

태그 페이지는 Hugo의 `tags` taxonomy로 만듭니다. 글뿐 아니라 `tags`가 있는 일반 페이지(이 문서처럼)도 함께 모읍니다.

```yaml
taxonomies:
  tag: tags
```

## 검색

검색 페이지는 `content/search/_index.md`로 만듭니다. 만들고 나면 헤더에 **검색** 버튼이 자동으로 생깁니다.

```yaml
---
title: 검색
searchExclude: true
---
```

- 빌드할 때 `/index.json`을 만들고, 브라우저에서 이 파일 하나만 읽어 검색합니다. 외부 서비스나 별도 서버가 필요 없습니다.
- 공백으로 나눈 단어가 모두 들어 있는 글을 찾습니다. 한국어는 단어 중간(예: "접근" → "접근성")도 찾습니다.
- 태그 칩으로 결과를 좁힐 수 있고, 주소(`?q=…&tag=…`)로 결과를 공유할 수 있습니다.
- 검색 대상에서 빼려면 페이지 front matter에 `searchExclude: true`를 씁니다.
- 본문은 글마다 앞의 3000자까지만 색인합니다.
