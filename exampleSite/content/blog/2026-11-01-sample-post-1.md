Hugo Module로 테마를 추가하고 `hugo.yaml`에서 module import를 지정하면 바로 쓸 수 있습니다. 헤더, 메가 메뉴, 푸터와 같은 KRDS 구성요소가 기본으로 들어 있습니다.

## 먼저 확인할 것

Hugo Extended 0.146.0 이상과 Go 1.24 이상이 필요합니다. GitHub Pages는 GitHub Actions에서 빌드하세요.

[설치 안내](https://www.krds.go.kr)는 저장소의 README를 따르면 됩니다.
